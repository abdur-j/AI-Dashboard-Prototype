# Passline

A restaurant operations dashboard built with React, Vite, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

The dev server runs on [http://localhost:5173](http://localhost:5173).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Build for production into `dist/` |
| `npm run preview` | Preview the production build locally |

## Stack

- **React 18** — UI
- **Vite 5** — dev server and bundler
- **Tailwind CSS 3** — styling
- **Recharts** — charts
- **lucide-react** — icons
- **PapaParse** — CSV parsing

## Project layout

```
index.html           # Vite entry point
src/main.jsx         # React root
src/App.jsx          # Dashboard application
src/index.css        # Tailwind directives and global styles
```
